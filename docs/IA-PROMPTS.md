# Prompts de IA · Eximia Code · TP1 · Grupo 12

Este documento registra los prompts utilizados como apoyo en la generación y revisión de recursos visuales del proyecto. La IA se utilizó como herramienta asistida: el equipo seleccionó, revisó y adaptó los resultados antes de incorporarlos al sitio.
- IA utilizada, modelo:
- **Nano Banana 2 (gemini-3.1-flash-image)**. 
- **Plan:** gratuito.
Se utilizó para:
- Generar las imágenes del logo, panel y avatares de los integrantes del grupo.

> **Criterio de autoría:** un recurso generado con IA no se incorporó automáticamente. Se evaluaron coherencia visual, legibilidad, relación con la identidad de Eximia Code, adaptación al tamaño de uso y consistencia entre páginas.

## 1. Orden del proceso visual

La generación se organizó en este orden para construir primero la identidad general y luego sus aplicaciones:

1. **Logo de Eximia Code** — definición de la identidad visual.
2. **Panel / ilustración principal** — aplicación de la identidad al concepto de software y logística.
3. **Avatares de los integrantes** — adaptación de la identidad a cada perfil.

## 2. Prompt base para el logo

> Diseñar un logo profesional y minimalista para un equipo ficticio de desarrollo de software llamado “Eximia Code”. La identidad debe combinar tecnología, software, datos, logística inteligente, planificación de rutas y trazabilidad B2B. Crear un símbolo de X simple, geométrico y reconocible a tamaño pequeño. Estética tecnológica corporativa, moderna y sobria, sin apariencia infantil, con formas limpias y buena legibilidad. 
>La propuesta debe funcionar tanto sobre fondo claro como sobre fondo oscuro y mantener una identidad visual coherente para un sitio web académico.Colores sugeridos: Utilizar una paleta tecnológica y corporativa, preferentemente basada en: azul oscuro o azul petróleo, asociado con confianza y tecnología; verde o turquesa como color de acento, asociado con eficiencia, movimiento y trazabilidad; blanco o gris claro para contraste. 
>También puede incorporarse un tono oscuro neutro para reforzar la identidad profesional.  paleta debe ser sobria, moderna y armónica, adecuada para una empresa de software B2B.Composición: Crear un isotipo compacto que combine visualmente una ruta, nodos de conexión y un punto de destino, integrado con algún detalle sutil de código.

## 3. Prompt base para el panel / ilustración principal

> Crear una ilustración tecnológica para la portada de un sitio web de un equipo de desarrollo de software llamado Eximia Code. Representar visualmente software empresarial, planificación inteligente de rutas, logística B2B, distribución, trazabilidad y operación de última milla. Incluir una composición de interfaz/panel digital con mapas, rutas, nodos, datos y elementos de seguimiento, con estética corporativa moderna.
> Evitar texto ilegible, marcas reales y elementos excesivamente decorativos. La composición debe funcionar como imagen principal de una landing page y conservar buena lectura visual en escritorio y móvil. El panel está dentro de un celular y una notebook formato responsive, como se vería realmente.

## 4. Prompt base para los avatares

> Crear un avatar ilustrado, profesional y consistente con una identidad visual de equipo de desarrollo de software. La persona debe representarse de forma amable y contemporánea, con una estética tecnológica corporativa y fondo limpio. Mantener composición cuadrada, buena iluminación, rasgos claramente visibles y suficiente contraste para utilizar la imagen como foto de perfil en una web. Evitar texto, logotipos de terceros y fondos demasiado cargados. 
>La serie de avatares debe compartir estilo visual aunque cada integrante tenga una apariencia diferenciada. Genera una imagen digital de alta resolución con estilo de ilustración 3D "Pixar-style" y renderizado cinematográfico. La composición debe presentar a un la persona de la foto, de estilo caricaturesco y expresivo, con LOS RASGOS DEL/la MODELO, vestido con una sudadera con capucha azul marino. El personaje debe estar sentado frente a un ordenador portátil abierto, tecleando, con una sonrisa amable y mirando directamente a la cámara. El ENTORNO: El fondo debe ser un entorno de oficina tecnológica moderno y oscuro, lleno de múltiples pantallas de ordenador borrosas que muestran código brillante en tonos azulados y cian, creando un ambiente de depth of field (profundidad de campo). 
>INTERFAZ UI (DERECHA): A la derecha del personaje, flotando en el aire, debe haber un gran panel de interfaz de usuario de realidad aumentada con bordes de neón cian brillantes. Este panel debe contener:En la parte superior, un rectángulo de neón cian prominente con texto nítido y moderno que diga: ROL (completar por el integrante ). En la parte inferior del panel de la interfaz, los siguientes textos y símbolos: "+4.3°C" junto a iconos de nube y termómetro, y debajo, un botón rectangular de neón que diga "GPS ONLINE". y debajo una franaja azul con los siguientes 4 íconos (completar por el integrante).  El estilo debe ser un renderizado 3D de estudio limpio, detallado y texturizado, manteniendo la estética de una ilustración de alta gama.

## 5. Revisión posterior a la generación

Después de generar los recursos, el equipo revisó:

- coherencia con el concepto de Eximia Code;
- legibilidad del logo en tamaños pequeños;
- consistencia visual entre avatares;
- relación entre imagen y rol profesional;
- comportamiento sobre fondo claro y oscuro;
- peso y dimensiones antes de convertir los recursos a WebP;
- necesidad de versiones optimizadas para diferentes tamaños.
- En el logo se agregó un borde blanco y se quitó el fondo, con Microsft Paint.

## 6. Uso responsable de IA

La IA se utilizó como apoyo para explorar alternativas y acelerar tareas de diseño/revisión. La decisión final sobre qué recurso utilizar, cómo integrarlo, qué textos conservar y qué modificaciones realizar correspondió al equipo.
